    Dentasay is a dental healthcare brand that treats patients travelling from abroad. The
    hard part of this work is not explaining the treatment; it is building a digital
    structure that people arriving from different countries, in different languages and
    with different expectations can all trust at the same time.

    We treated the website, social media, digital advertising, content production, SEO,
    influencer collaborations and international patient communication not as separate
    projects but as one strategy. Closing the distance between the person an ad brings in
    and the answer the clinic gives them was the core problem of the project.

    Today, we manage Dentasay's digital advertising operations across 20 countries in
    13 different languages.

  approach:
    heading: One Strategy, Nine Channels
    text: |-
      In health tourism it is not enough to run each channel well on its own. Even when an
      ad reaches the right person, the value is lost if the treatment page is not in their
      language or if their message is answered hours later. So we built the website,
      advertising, content, SEO, social media, influencer collaborations and patient
      communication as parts of the same plan.

  sections:
    - heading: International Growth Context
      text: |-
        Dentasay's audience is not in a single country. Today we run digital advertising
        for the brand across 20 countries in 13 different languages.

        That scale is not built by translating one campaign. Every market opens with a
        different first question: some ask about cost, some about length of stay, some
        about whether an interpreter is available. So we built country-level campaigns,
        treatment pages written for each market, and a communication structure separated
        by language.

        As the number of languages grows, the problem stops being translation and becomes
        localisation: the ad copy, the landing page and the first reply all have to be in
        the same language and the same tone.

    heading: The System That Came Out of It
    text: |-

      role has been to build the digital side of that expansion and make it multilingual.

Communication work tailored to different countries and languages strengthened the brand's digital visibility, patient trust and lead generation process.
